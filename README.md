# Raveen Sangaran - Engineering Portfolio

A modern, single-scroll portfolio website showcasing my mechatronic engineering projects, skills, and achievements.

## Features

- **Single-scroll design** with smooth navigation
- **Responsive layout** for all devices
- **Modern dark theme** with blue/teal accents
- **Interactive sections**: Home, About, Technical Skills, Projects, PLO Achievements, SWOT Analysis, Contact
- **Visual PLO progress bars** showing program learning outcomes
- **Project showcase** with detailed descriptions
- **Contact form** for inquiries

## Tech Stack

- **Frontend**: React.js with Vite
- **Styling**: Tailwind CSS
- **Backend**: Node.js with Express
- **Deployment**: Ready for Vercel (frontend) and any Node.js hosting (backend)

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
```bash
npm install
```

### Development

Run the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:3000`

### Build for Production

Build the frontend:
```bash
npm run build
```

### Run Production Server

Start the Node.js backend server:
```bash
npm run server
```

## Deployment

### Frontend (Vercel)

1. Push your code to GitHub
2. Import the project in Vercel
3. Set build command: `npm run build`
4. Set output directory: `dist`
5. Deploy

### Backend (Railway/Render/Heroku)

1. Deploy the Node.js server to your preferred platform
2. Ensure the `server/index.js` file is set as the entry point
3. Set environment variables if needed
